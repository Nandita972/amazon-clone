# amazon-clone

A responsive frontend clone of the Amazon homepage built using HTML, CSS, and JavaScript. This project simulates the core user interface and interactive elements of an e-commerce platform.

🔗 [View Live Demo](https://nandita972.github.io/amazon-clone/)

## Features
1. Responsive Design: Fully mobile-friendly layout.
2. Hero Image Slider: An infinite looping image carousel with manual navigation arrows and auto-play functionality.
3. Interactive UI:
    * Search Bar: Simulates a search query with real-time alerts.
    * Back to Top: Smooth scrolling functionality to return to the top of the page.
4. CSS Animations: Smooth transitions for hover effects and sliders.
  
## Technologies Used
1. HTML5: Semantic structure and layout.
2. CSS3: Flexbox for layout, media queries for responsiveness, and custom animations.
3. JavaScript (Vanilla): DOM manipulation for the slider and event handling.
4. Font Awesome: For icons (cart, search, menu bars).

## How to Run Locally
If you want to view this project on your local machine:
1.  Clone the repository:
    ```bash
    git clone [https://github.com/nandita972/amazon-clone.git](https://github.com/nandita972/amazon-clone.git)
    ```
2.  Open `index.html` in your web browser.
